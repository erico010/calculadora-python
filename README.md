# Calculadora em Python

Meu primeiro projeto desenvolvido em Python.

Neste projeto pratiquei conceitos básicos da linguagem, como entrada de dados, estruturas condicionais e formatação de resultados.

## Conceitos utilizados

* `print()` para exibir informações
* `input()` para receber dados do usuário
* `if / elif / else` para tomar decisões
* `.format()` para formatar e exibir os resultados

## Funcionalidades

* Soma
* Subtração
* Multiplicação
* Divisão
* Validação do operador
* Tratamento de divisão por zero

## Tecnologia

* Python

## Objetivo

Este projeto foi desenvolvido como forma de praticar os conceitos básicos de Python e dar início ao meu portfólio de programação.
